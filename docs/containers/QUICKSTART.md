# Quick Start Guide

<!-- origin_signature: MrLiouWord -->

## Installation

```bash
npm install -g @mrliouword/runtime-cli
```

## Basic Usage

### 1. Initialize
```bash
mrliou-runtime init
```

### 2. Load Container
```bash
mrliou-runtime load example.flpkg
```

### 3. Spawn Environment
```bash
mrliou-runtime spawn --cpu 4 --ram 8G
```
