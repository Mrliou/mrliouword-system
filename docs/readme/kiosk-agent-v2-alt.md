## 概述

這是 Kiosk Agent v2 的替代實現方案，使用不同的技術棧以滿足特定需求。

| 特性 | 標準版本 | 替代版本 |
|------|---------|---------|
| 前端框架 | React | Vue.js |
| 狀態管理 | Redux | Pinia |
| 構建工具 | Webpack | Vite |
| 部署方式 | SPA | SSR |

## 技術棧

- **前端**: Vue.js 3 + TypeScript
- **狀態管理**: Pinia
- **UI 框架**: Element Plus
- **構建**: Vite
- **渲染**: Nuxt 3 (SSR)

## 安裝與配置

### 安裝依賴

```bash
npm install @mrliouword/kiosk-agent-v2-alt
```

### 開發模式

```bash
npm run dev:kiosk-alt
```

### 生產構建

