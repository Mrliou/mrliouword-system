## 8. 驗證方法

1. 依序查閱 Top Index → Governance/Rights → Origin/Provenance → Current Mode → Task → Gate → Backfill。
2. 逐項核對第 2 節歸屬欄位與第 4 節公式。
3. 由原始影像持有者執行 `sha256sum IMG_*.jpeg`，與 `.sha256` 檔比對。
4. 以 JSON parser 驗證 manifest；確認 `artifact_count = 20`、所有 SHA-256 為 64 位小寫十六進位且互不重複。
5. 對照外部 changelog，只把可公開查證的功能與日期列為外部容器局部狀態。
6. 使用 Git commit 與 Pull Request 保留公開時間、差異與審閱軌跡。
