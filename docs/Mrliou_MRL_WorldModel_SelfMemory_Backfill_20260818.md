## Continuity Rule

A system should be able to preserve and reconstruct how it became its current state.

```text
Origin
-> Initial State
-> Identity
-> Memory
-> Experience
-> Transformation
-> Current State
-> Trace
-> Verify
-> Backfill
-> Evolution
```

Initial state provides a reference point. Memory preserves the path. Current state may evolve without erasing the origin or historical transitions.

## Complete Abstraction / Difference Preservation

Completeness does not mean forcing all entities into one identical form.

```text
Complete State
= Elements
+ Differences
+ Relations
+ History
+ Change
+ Perspective
```

Core rule: `Difference is not error.`

A coherent non-mainstream component is not invalid merely because it differs from a dominant convention. Functional failure, security risk, integrity failure, or other evidenced constraints may justify deactivation, replacement, quarantine, or restricted execution, but the historical role and provenance remain recordable.

## No Silent Erasure

State transition is not historical deletion.

Suggested lifecycle states:

```text
Active
Archived
Dormant
Historical
Quarantined
Superseded
```

The system should distinguish current execution status from historical existence.

## Internal Exploration First

`向內探索` means first recognizing, understanding, and valuing what already exists internally before assuming that an external replacement is required.

```text
Recall
-> Trace
-> Compare
-> Recompose
-> Validate
-> Expand only if needed
```

This is not rejection of external knowledge or external systems. It is an ordering principle: inspect internal assets, history, capability, and relationships before unnecessary external acquisition or replacement.

Historical records are therefore not only archives; they can function as reusable material for future recomposition and problem solving.

## Self Model

A system that only produces output is not sufficient for the MRL target architecture. The target is a system that can describe and trace its own operation at an engineering level.

Required properties include:

```text
Self-description
Self-observation
Traceability
Recoverability
```

This does not by itself establish human-like consciousness. It establishes a verifiable engineering goal: stronger observability and explainability of origin, state, history, transformations, dependencies, and recovery paths.

## Memory and Initial State

Memory and initial state are complementary.

```text
Initial State without Memory
-> reference exists, continuity is weak

Memory without Initial State
-> history exists, baseline is unclear

Initial State + Memory + Trace
-> continuity can be reconstructed
```

The initial state should be preserved as an origin/reference record while runtime state remains free to evolve.

## Learning Without Self-Erasure

Learning or imitation should add capability rather than automatically replace existing capability.

```text
Know Self
-> Preserve Existing Capability
-> Observe External Systems
-> Imitate / Learn
-> Translate
-> Integrate
-> Expand
```

Core rule: `Learning != Self-Erasure`.

The principle is intended as a general systems principle, not an AI-only rule. It may be applied to people, organizations, companies, states, cultures, software systems, AI systems, components, and other modeled entities where the abstraction is appropriate.

## Respect and Difference

Respect does not require sameness, agreement, or the suspension of verification.

```text
Different != Wrong
Minority != Invalid
Non-mainstream != Meaningless
```

A differing idea or method should first be understood in its own context, then compared, evidenced, tested, or rejected on relevant grounds rather than on popularity or scale alone.

Related invariants:

```text
Scale != Truth
Quantity != Correctness
Popularity != Validity
Power != Legitimacy
Projection != Origin
```

MRL does not require mainstream systems to become MRL, and MRL should not be redefined solely to imitate mainstream systems. The intended relation is coexistence, translation, comparison, verification, and collaboration without forced identity collapse.
