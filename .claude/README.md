# Mrliouword 專案說明

這是使用 Mrliouword Agent SDK 建立的專案。

## 可用 Agent

- **DataAnalyzer** - 數據分析 Agent
- **CodeReviewer** - 程式碼審查 Agent
- **TestGenerator** - 測試生成 Agent
- **DocWriter** - 文件撰寫 Agent
- **WorkflowOptimizer** - 工作流優化 Agent

## 可用技能

查看 `skills/` 目錄了解各項技能的詳細說明。

## 快捷指令

查看 `commands/` 目錄了解可用的快捷指令。

## 開始使用

```bash
# 安裝依賴
pip install -r requirements.txt

# 使用 CLI
mrliouword analyze data.csv
mrliouword review code.py
```
